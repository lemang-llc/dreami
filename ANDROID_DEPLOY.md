# Android Deployment Guide

## Overview

Google Play requires a release AAB (Android App Bundle) signed with a **release keystore** — not the debug keystore. The project currently ships with `signingConfig signingConfigs.debug` on the release build type, which is why Play Console flags uploads as debug builds. Follow the steps below once to fix this permanently.

---

## Step 1 — Generate a release keystore

Run this once and store the keystore file somewhere safe (outside the repo).

```bash
keytool -genkey -v \
  -keystore ~/dreami-release.keystore \
  -alias dreami \
  -keyalg RSA \
  -keysize 2048 \
  -validity 10000
```

You will be prompted for:
- **Keystore password** — pick something strong, save it
- **Key password** — can be the same as keystore password
- **Distinguished name fields** — name, org, country, etc.

> **Critical:** Never commit the `.keystore` file or its passwords to git. If you lose this file, you cannot update your app on Play Store.

---

## Step 2 — Store credentials in ~/.gradle/gradle.properties

Add the following to `~/.gradle/gradle.properties` (user-level, **not** `android/gradle.properties`):

```properties
DREAMI_STORE_FILE=/Users/yourname/dreami-release.keystore
DREAMI_STORE_PASSWORD=your_keystore_password
DREAMI_KEY_ALIAS=dreami
DREAMI_KEY_PASSWORD=your_key_password
```

**Why not `android/gradle.properties`?**
The `android/` folder is listed in `.gitignore` so it is never committed, but it is fully regenerated by `npx expo prebuild --clean`. Anything written there will be silently wiped on the next prebuild. The user-level file at `~/.gradle/gradle.properties` is permanent and never touched by Expo.

---

## Step 3 — Wire the release signing config in build.gradle

Edit `android/app/build.gradle`. Replace the `signingConfigs` and `buildTypes` blocks:

```groovy
signingConfigs {
    debug {
        storeFile file('debug.keystore')
        storePassword 'android'
        keyAlias 'androiddebugkey'
        keyPassword 'android'
    }
    release {
        storeFile file(DREAMI_STORE_FILE)
        storePassword DREAMI_STORE_PASSWORD
        keyAlias DREAMI_KEY_ALIAS
        keyPassword DREAMI_KEY_PASSWORD
    }
}
buildTypes {
    debug {
        signingConfig signingConfigs.debug
    }
    release {
        signingConfig signingConfigs.release   // <-- was signingConfigs.debug
        def enableShrinkResources = findProperty('android.enableShrinkResourcesInReleaseBuilds') ?: 'false'
        shrinkResources enableShrinkResources.toBoolean()
        minifyEnabled enableMinifyInReleaseBuilds
        proguardFiles getDefaultProguardFile("proguard-android.txt"), "proguard-rules.pro"
        def enablePngCrunchInRelease = findProperty('android.enablePngCrunchInReleaseBuilds') ?: 'true'
        crunchPngs enablePngCrunchInRelease.toBoolean()
    }
}
```

---

## Step 4 — Build the release AAB

```bash
cd android && ./gradlew bundleRelease
```

Output: `android/app/build/outputs/bundle/release/app-release.aab`

---

## Step 5 — Upload to Play Console

1. Go to Play Console → your app → **Production** (or Internal Testing)
2. Create a new release
3. Upload `app-release.aab`
4. Fill in release notes and submit for review

---

## Version bumps

Before each Play Store release, increment `versionCode` (must always increase) and update `versionName` in `android/app/build.gradle`:

```groovy
defaultConfig {
    versionCode 2          // increment by 1 each release
    versionName "1.1.0"    // human-readable, shown on Play Store
}
```

---

## Quick reference

| Task | Command |
|------|---------|
| Build release AAB | `cd android && ./gradlew bundleRelease` |
| Build release APK (sideload) | `cd android && ./gradlew assembleRelease` |
| Run release on device | `npx expo run:android --variant release` |
| Clean build cache | `cd android && ./gradlew clean` |
| Verify AAB signing | `keytool -printcert -jarfile app/build/outputs/bundle/release/app-release.aab` |
